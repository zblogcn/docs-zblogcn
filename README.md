# Z-Blog 官方文档

本仓库为 Z-blog PHP 与 Z-blog ASP 的官方文档源码，构建后部署在 [https://docs.zblogcn.com](https://docs.zblogcn.com)。

## 贡献方式
欢迎参与Z-Blog文档的编写，贡献方式如下：

1. Fork本仓库
2. 在`src`目录下编写文档
3. 提交Pull Request

### 预览
```bash
git clone https://github.com/zblogcn/docs-zblogcn.git
# 链接请替换为fork后仓库地址
npm install
npm run docs:dev
```
